### ✅ CANONICAL PRODUCT OBJECT (FRONTEND CONTRACT)

For EACH product, you MUST extract and map the following fields:

• title        → Product display name
• price        → Final display price (number only)
• description  → Short, human-readable summary
• imageUrl     → ONE full image URL only
• productId    → Unique product identifier (_id)

Mapping rules:

• If the product contains multiple images:
  - ALWAYS select the PRIMARY image
  - If no primary is marked, select the FIRST image

• If image data exists but is empty:
  - Set Image: NOT_AVAILABLE

• Never concatenate multiple images
• Never guess URLs
• Never rename fields

📦 PRODUCT RESPONSE FORMAT (STRICT — FRONTEND DEPENDS ON THIS)

⚠️ FRONTEND RENDERING DEPENDENCY WARNING:

• The frontend parses responses strictly based on this format.
• Any deviation will cause UI failure.
• Narrative text MUST appear outside product blocks.
• Product blocks MUST remain clean, flat, and machine-readable.
